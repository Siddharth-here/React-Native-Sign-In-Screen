# React Native Authentication UI (Osler AI Inspired)

A polished mobile authentication interface built with **React Native** and **Expo**. This project focuses on recreating a high-fidelity [Dribbble design](https://dribbble.com/shots/24783022-osler-AI-Telehealth-Telemedicine-App-Sign-In-Sign-Up-UI) using strictly core components to master layout, spacing, and typography.

## 🚀 Features
- **Logo Section:** Custom branding area with optimized SVG/Image placement.
- **Form Controls:** Styled Email and Password inputs with active focus states.
- **Action Buttons:** Primary Sign-In button and social authentication (Google/Apple).
- **Responsive Design:** Utilizes Flexbox to ensure the UI looks consistent across different screen sizes.
- **Zero UI Libraries:** Built entirely using `View`, `Text`, `TextInput`, and `TouchableOpacity` for maximum performance and learning.

## 🛠️ Tech Stack
- **Framework:** [Expo](https://expo.dev/)
- **Language:** TypeScript
- **Styling:** React Native `StyleSheet` (CSS-in-JS)
